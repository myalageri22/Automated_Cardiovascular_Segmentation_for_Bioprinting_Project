# Superseded representative-case panels

Panels from the first cohort run, written as `<case>_slices.png` /
`<case>_meshes.png`. That naming has no variant in it, so a case selected for
more than one correction strategy had its panel overwritten by whichever
strategy rendered last, and the mesh panels show "Original mesh unavailable"
because the control mesh was looked up under a column name the paired table
does not contain.

Both faults were in the rendering only. No measurement, statistic, table or
numeric figure was affected. The replacements are the `<case>__<variant>_*.png`
files one directory up, regenerated by
`experiments/topology_correction/rerender_failure_panels.py` from the same
`selected_cases.csv` rows. These originals are kept for audit.
